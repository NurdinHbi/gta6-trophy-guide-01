The Leonida Trophy Guide: an offline web app that tracks all 55 GTA VI PlayStation 5 trophies, with a sourced guide for each one, a five-stage roadmap to the Platinum, kind and grade filters, a spoiler setting, and progress export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
